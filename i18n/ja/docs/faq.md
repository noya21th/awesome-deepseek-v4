## 基礎

### DeepSeek V4 とは？
DeepSeek-AI が 2026-04-24 にリリースした 2 つのオープンウェイト MoE 言語モデル：**V4-Pro**（1.6T / 49B アクティブ）と **V4-Flash**（284B / 13B アクティブ）。両方とも 1M トークンコンテキスト、Thinking/Non-Thinking デュアルモード、MIT ライセンス。

### V4 は本当にオープンソース？
**ウェイト：はい、MIT。** ダウンロード、実行、fine-tuning、商用利用すべて無条件。
**学習コードとデータ：いいえ。** DeepSeek は詳細な技術レポートを公開していますが、完全な事前学習パイプラインは非公開。Llama、Qwen 同様の「オープンウェイト」モデルのパターン—「オープンウェイト」は OSI 的な「オープンソース」とは違います。

### ライセンスで許されることは？
MIT なので：商用 ✅、改変 ✅、再配布 ✅、私的利用 ✅。再配布には MIT 表記が必須。AUP（許容使用ポリシー）の重ね合わせはありません。

### V4-Pro と V4-Flash の違い？

| | V4-Pro | V4-Flash |
|---|---|---|
| 総パラメータ | 1.6T | 284B |
| アクティブパラメータ | 49B | 13B |
| 品質帯 | ≈ GPT-5.4 / Claude Opus 4.6 | ≈ Claude Haiku / GPT-5-Mini |
| API 料金（入/出） | $1.74 / $3.48 | $0.14 / $0.28 |
| セルフホスト下限 | 16× H200 | 8× H200 |

コスト重視なら Flash から、品質重視なら Pro。

## 比較

### V4 vs Claude 4.6 / GPT-5.4 / Gemini 3.1-Pro ?
短答：**コードで SOTA、推論で互角、世界知識で差あり。** 詳細は [比較表](./comparison.md)。

### V4 vs Qwen 3.5 / Llama 4 / GLM-5 ?
どれも強力なオープンウェイト選択肢。V4 はコードと長文で先行、Llama 4 はエコシステム最成熟、Qwen は多言語最強、GLM-5 は軽量。

### V4 はコードで本当に Opus より良い？
公開ベンチマーク（LiveCodeBench 93.5 vs 88.8、Codeforces 3206）ではイエス。SWE-Bench Verified は 80.6 vs 80.8 で互角。**自分のコードベースで両方評価すべき。** 公開ベンチマークはプロキシに過ぎません。

## 実務

### 既存の OpenAI / Claude コードで V4 を使える？
使えます。V4 は **OpenAI ChatCompletions と Anthropic Messages の両方**に対応。`base_url` とモデル名を変えるだけ。

### 無料枠はある？
DeepSeek は新規アカウントに無料クレジットを提供してきました。現行条件は platform.deepseek.com を確認。サードパーティホスト（OpenRouter、Together など）の無料層も利用可能。

### レートリミットは？
Preview 期間は公式数値未公開。コミュニティからは Flash は寛容、Pro はややタイトという報告。本番用途では DeepSeek 営業またはサードパーティホストの SLA を検討。

### マルチモーダル（画像/音声/動画）対応？
**非対応——Preview はテキストのみ。** 技術レポートで今後の課題として明記。

### Function calling / Tool use 対応？
対応。OpenAI 互換 `tools` スキーマ + Anthropic 互換 `tools`（各エンドポイント）。[examples/python_tool_calls.py](../../../examples/python_tool_calls.py) 参照。

### Thinking モードとは？
V4 のデュアルモード。推論トレースを可視化する（`thinking: enabled`）か、直接回答する（`thinking: disabled`）。同一モデル、同一価格、異なる出力スタイル。難推論/コードは ON、簡単な会話は OFF。

### コンテキストウィンドウは実際どれくらい使える？
**1,000,000 トークン。** ただし技術レポートでは **128K 超で検索精度が低下**と明記。1M 入れられるが深部の精密検索は不安定。精度重視なら RAG を併用。

## セルフホスト

### ノート PC で V4 動く？
無理。V4-Flash FP8 だけでも ~160GB のウェイト。最低現実構成は 8× H100 80GB。

### H100 1 枚で V4 動く？
無理。極端に量子化した Flash + 短コンテキストなら理論上可能ですが品質は未知数。シングル GPU ユーザーはマネージド API 推奨。

### vLLM / SGLang / TensorRT-LLM サポート？
vLLM、SGLang は Day-0 サポート。TensorRT-LLM は NVIDIA リリースノート参照。[local-deployment.md](../../../getting-started/local-deployment.md)。

### V4 は華為昇騰で本当に動く？
HN の報道では：**はい。** DeepSeek は華為チップで V4 を学習・サービスしており、本番スタックで CUDA 非依存。AI サプライチェーンのデカップリングの重要なシグナル。詳細は華為 MindIE ドキュメント。

## プライバシー / ガバナンス

### DeepSeek は私のプロンプトで学習する？
公式 API：platform.deepseek.com のプライバシーポリシーを確認。サードパーティホスト（Together、Fireworks など）：学習に使わないプロバイダを選択。セルフホスト：データは自社ネットワーク外に出ない。

### V4 は検閲される？
中国系ラボが学習した全てのモデル同様、V4 には特定トピック（特に中国政治に関する敏感事項）で西側モデルと異なるガードレールがあります。商用用途の大半には無関係。影響がある場合：
- **API 上**：フィルターはサーバー側、変更不可
- **ウェイト上**：コミュニティによる "abliteration" などの手法あり、ただし公式非推奨

### 規制対象ワークロード（医療/法律/金融）で安全？
- **法律的**：MIT で許可
- **コンプライアンス**：監督官庁次第。VPC 内での V4 セルフホストは HIPAA / SOC2 / GDPR と両立可能
- **API 上**：DeepSeek の認証状況次第

### 販売する製品に組み込める？
できます。MIT は商用無制限。モデル出所（DeepSeek）を About ページやドキュメントに明記するのがベストプラクティス。
