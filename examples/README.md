# Examples

Runnable, minimal examples. Every file is under 60 lines so you can read it before you run it.

```bash
pip install openai anthropic
export DEEPSEEK_API_KEY=sk-...
python python_openai_basic.py
```

| File | What it shows |
|---|---|
| [python_openai_basic.py](./python_openai_basic.py) | Drop-in OpenAI SDK call to V4 |
| [python_anthropic_basic.py](./python_anthropic_basic.py) | Drop-in Anthropic SDK call to V4 |
| [python_thinking_mode.py](./python_thinking_mode.py) | Enable V4's Thinking mode for hard problems |
| [python_tool_calls.py](./python_tool_calls.py) | Function / tool calling, end-to-end |
| [curl_basic.sh](./curl_basic.sh) | Raw HTTP call, no SDK |

More examples welcome — see [CONTRIBUTING.md](../CONTRIBUTING.md).
